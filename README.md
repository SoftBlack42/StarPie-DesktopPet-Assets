# StarPie 桌宠素材

蓝鲸女仆素材已撤回，当前主分支和 Release 不再提供该素材。此前版本仍保留在 Git 历史；本次撤回不重写仓库历史。

正在制作以 StarPie 软件图标为参考的原创桌宠「星派灵」，采用蓝紫色轮盘、白色指针和四角星元素。新素材尚未发布，需完成 12 状态素材验证与人工预览验收。

本仓库只提供桌宠素材，不包含 StarPie 主程序或桌宠插件。支持的运行素材格式为 12 张 512×512 透明 PNG；在“管理桌宠 → 导入文件夹”导入解压目录。

## 维护工具

`tools/Test-PetAssets.ps1` 检查素材；`tools/Pack-PetAssets.ps1 -PackId <ID>` 生成素材包。每套素材附有独立来源与分发记录；尚未获发布确认的素材只准备本地候选包。
