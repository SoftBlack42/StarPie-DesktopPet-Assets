# StarPie 桌宠素材

本仓库当前仅公开蓝鲸女仆 v1.0.0，包含常驻、眨眼、点击反馈、拖动悬空及八方向指向的12张512×512透明PNG。图片由内置imagegen参考用户提供形象生成，SoftBlack42负责桌宠整理与发布。

## 下载和使用

[下载蓝鲸女仆素材包](https://github.com/SoftBlack42/StarPie-DesktopPet-Assets/releases/download/bluewhale-maid-v1.0.0/StarPie-PetAsset-local.bluewhale-maid-1.0.0.zip) · [校验值](https://github.com/SoftBlack42/StarPie-DesktopPet-Assets/releases/download/bluewhale-maid-v1.0.0/SHA256SUMS.txt)

解压素材包，在StarPie“管理桌宠→导入文件夹”选择解压目录，再点击“使用此形象”。当前播放器不直接导入ZIP。该仓库只提供素材，不包含主程序或桌宠插件；需要已安装支持此12状态格式的桌宠插件。
